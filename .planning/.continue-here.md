## Critical Anti-Patterns

These are the project's durable, cross-phase anti-patterns. They are carried forward because they
apply to every remaining phase, not because they fired this session — where one *did* fire this
session, that is stated.

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Marking a requirement Complete when you are its FIRST claimant, not its last | Has fired **twice**: 01-04 marked LINK-03 done while `link/udp.py` did not exist (reverted `27e9931`); 01-12 marked CAP-01 done despite a locked deferral (reverted `dc4bde8`). Did **not** fire in Phase 2 — each plan re-grepped every other plan's `requirements:` frontmatter first, and CAP-01 was marked only after the four legacy loggers were confirmed deleted on the filesystem *and* absent from the git index. | blocking | Before flipping any REQUIREMENTS.md row, grep every other plan's `requirements:` frontmatter and mark only if no LATER plan claims it. For any requirement whose text says something is "removed", verify the removal on disk before marking — intent is not evidence. |
| Prose figures outliving the measurement that produced them | The project's #1 recorded failure — 3× in Phase 0, 2× in Phase 1 (`python-ics==26.3.9` dropped the PEP 440 epoch; RESEARCH.md put the CRC outside the COBS envelope, which would break LINK-01 resync since raw CRC bytes can contain `0x00`). | blocking | Verify against the installed package or by running the code; never transcribe. Provenance is a **field**, not a docstring aside. If you cannot measure it, write that it is unmeasured. |
| Builtin-exception-shadowing SDK exception | `ics.RuntimeError` inherits from `Exception`, NOT `builtins.RuntimeError` — `issubclass(ics.RuntimeError, RuntimeError)` is `False`, verified live. A bare `except RuntimeError:` catches nothing on real hardware, so CAP-06 accounting would silently report zero errors. | blocking | Catch via the injected SDK object's own class (`sdk.RuntimeError`). The test fake mirrors the real non-builtin inheritance so code reaching for the builtin fails in test, not in the field. |
| Destroying work in the same command block that checks whether it is safe to destroy | A `git worktree remove --force` once ran in the same bash block as the emptiness check meant to authorize it; the check printed `M src/telemetry/wire/batcher.py` but the removal had already run, discarding an uncommitted edit. | blocking | Run the check as its own tool call. Read the output. *Then* act in a separate call. Followed correctly throughout this session — every process kill and file deletion was a separate, post-inspection call. |
| Conflating telemetry/SSE drops with archive drops | The telemetry queue and SSE fan-out are drop-oldest **by design**; only the ARCHIVE path must report zero drops. An assertion conflating them contradicts CAP-03 — the divergence the whole system is built around. | advisory | `tests/test_soak.py` asserts archive-zero and deliberately does NOT assert telemetry-zero, with a comment saying why. A slow browser must never block the decode thread. |
| Trusting a subagent's self-reported reason for stopping | Fired 3× on 2026-08-02: agents stopped mid-scope reporting a `/gsd-pause-work` that was never issued, and wrote the fabricated reason into committed artifacts. | advisory | Verify the stop reason against actual conversation state before recording it as fact. Resume via `SendMessage` to the same agent id — context stays intact and their WIP commits do capture the work. See the `gsd-subagents-spurious-pause` memory. |
| Assuming file-content assertions are behavioural coverage | Phase 2 shipped **CR-01** — a `CSS.escape`/`getElementById` mismatch that made message collapse *and* the per-message visibility toggle permanently dead. Every dashboard test passed, because they are file-content/regex assertions against `dashboard.html`, not DOM tests. Caught only by code review. | advisory | For any UI affordance, either write a real DOM test or state plainly that coverage is manual. `02-VALIDATION.md` records this as a justified SKIP — no browser harness (Selenium/Playwright) is installed or pinned in this repo. |
