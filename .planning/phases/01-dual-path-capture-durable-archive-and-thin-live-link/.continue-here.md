## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Marking a requirement Complete when you are its FIRST claimant, not its last | The tracer (01-04) marked CAP-03/04, ARCH-01/05, LINK-01..04, GND-01, OPS-04/05 Complete after proving ONE frame through the spine. LINK-03 was marked done while `src/telemetry/link/udp.py` did not yet exist. Reverted in `27e9931`. | blocking | Before marking any REQUIREMENTS.md row Complete, grep the other plans' `requirements:` frontmatter. Mark it only if no later plan still claims it. Every executor from 01-05 onward was given this rule and followed it. |
| Prose figures outliving the measurement that produced them | This project's #1 recorded failure — 3× in Phase 0, twice more in Phase 1: RESEARCH.md's `python-ics==26.3.9` dropped the PEP 440 epoch (real pin is `1!26.3.9`), and its Pattern 7 framing sketch put the CRC *outside* the COBS envelope, which would break LINK-01 resync because raw CRC bytes can contain `0x00`. | blocking | Verify against the installed package or run the code; never transcribe. Every measured figure carries provenance as a **field**, not a docstring aside. |
| Builtin-exception-shadowing SDK exception | `ics.RuntimeError` inherits from `Exception`, NOT `builtins.RuntimeError` — `issubclass(ics.RuntimeError, RuntimeError)` is `False`, verified live. A bare `except RuntimeError:` catches nothing on real hardware, so CAP-06 accounting would silently report zero errors. | blocking | Catch via the injected SDK object's own class (`sdk.RuntimeError`). The test fake mirrors the real non-builtin inheritance so code reaching for the builtin fails in test, not in the field. |
| Conflating telemetry drops with archive drops | The telemetry queue is drop-oldest **by design**; only the ARCHIVE path must report zero. An assertion conflating them contradicts CAP-03 — the divergence the whole phase is built around. | advisory | `tests/test_soak.py` asserts archive-zero and deliberately does NOT assert telemetry-zero, with a comment saying why. |
