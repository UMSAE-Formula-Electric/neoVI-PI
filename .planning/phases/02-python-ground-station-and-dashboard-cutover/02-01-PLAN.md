`make_handler_class(*, hub, snapshot_provider)` returns a `BaseHTTPRequestHandler` subclass with

queue in a `finally`. This mirrors `ArchiveRunner._run`'s poll-with-timeout shape.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → ground station HTTP | Untrusted request paths and unbounded connection counts cross here. No authentication exists anywhere in this project's design. |
| radio/UDP link → decode loop | Already hardened in Phase 1 (COBS+CRC discard-and-count, DBC decode failures counted). Unchanged by this plan. |
| decode thread → HTTP handler threads | Shared mutable state crosses a thread boundary; a torn read would show a half-written message to the pit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-02-02 | Denial of Service | per-client SSE queue | medium | mitigate | Bounded `queue.Queue(maxsize=256)` with drop-oldest and a counted loss; a client that never reads cannot grow server memory. Task 2. |
| T-02-03 | Denial of Service | unbounded count of concurrent SSE clients | low | accept | Pit-side, loopback-by-default, single-engineer tool on a physically local network.
