## Critical Research Findings (verified live — do NOT regress)

1. **`frame.timestamp_us` is NOT wall-clock** — it is neoVI hardware `TimeSystem` × the explicitly
   named `TIME_SYSTEM_TO_MICROSECONDS_UNCONFIRMED` constant. The state dict's `ts`, which drives the
   UI-SPEC's 3000 ms staleness dimming, must be stamped with the ground station's own `time.time()`
   at receive time.
2. **Decoded records carry NO `channel` field** — GND-01 kept it off the wire by design. Derive
   channel ONCE at startup via `assign_rates(db, gate_config)` + `logger_config.channels`.
3. **`httpd.shutdown()` from the signal handler is a same-thread deadlock** — `serve_forever()` and
   Python signal handlers both run on the main thread. Verified via
   `inspect.getsource(socketserver.BaseServer.shutdown)`. The call must come from the decode thread.
4. **`EventSource` gives up PERMANENTLY on any non-200 or wrong content-type** — stricter than the
   WebSocket client it replaces. `/events` must send 200 + `text/event-stream` unconditionally before
   anything fallible.
