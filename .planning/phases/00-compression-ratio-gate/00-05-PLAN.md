<interface_contract>
## Rate model (D-03)

```
MessageRate  frozen dataclass
    frame_id: int, is_extended: bool, name: str, sender: str, bus: str,
    period_us: int, rate_hz: float, rate_source: str    # "gen_msg_cycle_time" | "scaled_default"

assign_rates(db, config: GateConfig) -> list[MessageRate]
bus_totals(rates: list[MessageRate]) -> dict[str, float]     # bus name -> achieved frames/s
RateModelError(Exception)
```

Algorithm, in order:

1. Assign each message a bus from `config.bus_assignment["by_ecu"][sender]`, falling back to `config.bus_assignment["default_bus"]` when the message has no declared sender or an unmapped one.
2. A message whose `cycle_time` is not None gets `period_us = cycle_time * 1000` and `rate_source = "gen_msg_cycle_time"`. Read `cycle_time` from the loaded database at runtime — never hardcode how many messages carry it (RESEARCH.md Pitfall 3: the "~21" figure already drifted once; the file says 23).
3. Every remaining message gets a seed period from `config.default_period_ms_by_ecu[sender]`, falling back to the `_default` key.
4. Per bus, compute `declared_fps` from step 2 and `seed_fps` from step 3. Solve one scale factor per bus so `declared_fps + scaled_seed_fps == bus_targets[bus].target_fps`, and apply it to every step-3 message's period on that bus.
5. If `target_fps - declared_fps <= 0` for a bus, raise `RateModelError` naming the bus, the declared total, and the target. Do not clamp, do not drop messages, do not silently overshoot.

## Entropy model (D-02)

```
BRACKET_NAMES = ("best", "typical", "worst")

PayloadMutator(message, bracket: EntropyBracket, rng: random.Random)
    .next_payload() -> bytes
    .selector_value -> int | None      # current multiplexer selector, None for non-multiplexed
```

The mutator holds a dict of raw signal values and packs with `message.encode(values, scaling=False, padding=True, strict=False)` so cantools owns bit ordering, start bits, and byte order. Per emitted frame:

- Signals classified `rolling_counter` or `checksum` by `telemetry.measure.classify.classify_signal` increment modulo `2 ** length` when `bracket.counter_increments` is true.
- Signals classified `high_entropy_analog` have their lowest `bracket.analog_dither_bits` bits re-randomized with probability `bracket.analog_dither_prob`.
- Every other signal is re-drawn uniformly from its declared range with probability `bracket.discrete_change_prob`.
- Each `PayloadMutator` owns its own `random.Random` instance seeded from `(config.seed, frame_id, bracket_name)` — never the global `random` module, so per-message streams stay independent and reproducible.

**Multiplexer cycling (RESEARCH.md Pitfall 1).** For a multiplexed message the mutator advances `selector_value` round-robin through `sorted(set(all multiplexer_ids declared on that message))` on every emitted frame, and builds the value dict from the selector plus the signals active under that selector plus every non-multiplexed signal. Consecutive frames of the same multiplexed ID therefore carry different selectors, which is exactly the mux-transition cost the report must expose.

## Generator

```
SyntheticFrameSource(db, dictionary, config: GateConfig, bracket_name: str,
                     duration_s: float | None = None, only_message_names: Sequence[str] | None = None)
    .frames() -> Iterator[RawFrame]
    .rates -> list[MessageRate]
```

Emission is a deterministic merge over the per-message schedules: each message fires at multiples of its `period_us` from t=0; ties break by ascending `frame_id` then `is_extended`. Timestamps are integer microseconds. `only_message_names` narrows the stream without changing any other message's schedule, preserving the tracer's single-ID mode.
</interface_contract>

| Boundary | Description |

| `gate.json` → rate model | Human-authored bus targets and default periods determine every frame rate in the stream |
| Generator → measurement | A generator that flatters the encoding produces a number that passes a gate the real bus would fail |
| cantools `message.encode` → payload bytes | Signal metadata edge cases (a `None` minimum, an empty multiplexer set, a signal wider than the message) cross here |
