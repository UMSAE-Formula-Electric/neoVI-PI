<interface_contract>
## Classification contract

```
CATEGORIES = ("rolling_counter", "checksum", "multiplexed", "high_entropy_analog", "other")

SignalClassification  frozen dataclass
    signal_name: str, message_name: str, frame_id: int, is_extended: bool,
    category: str, reason: str

MessageClassification  frozen dataclass
    frame_id: int, is_extended: bool, name: str,
    categories: frozenset[str], signals: tuple[SignalClassification, ...]

classify_signal(signal, message) -> tuple[str, str]        # (category, reason)
classify_message(message)        -> MessageClassification
classify_database(db)            -> dict[tuple[int, bool], MessageClassification]
category_members(classifications) -> dict[str, list[MessageClassification]]   # every key in CATEGORIES present, empty lists included
```

`category_members` returns a dict whose keys are exactly `CATEGORIES` — an empty bucket is an empty list, never a missing key. This is what makes "no checksums on this bus" distinguishable from "the classifier never looked".

## Classification rules (D-04, structural first)

Apply in this order; the first match wins, and `reason` records which rule fired and the values that triggered it.

1. **multiplexed** — `message.is_multiplexed()` is True. Purely structural; cantools reports it directly. Applies to the message, so every signal in a multiplexed message inherits this category.
2. **checksum** — the counter-shaped test below matches AND the signal's length is 8 or 16 bits AND its bit position places it wholly within the final byte(s) of the message. Name substrings `crc`, `checksum`, `chk` are a positive override that promotes a signal into this category regardless of shape.
3. **rolling_counter** — counter shape: `scale == 1` and `offset == 0` and `length <= 8` and `minimum == 0` and `maximum == (2 ** length) - 1`. Name substrings `rollingcounter`, `rolling_counter`, `alivecounter`, `alive_counter`, `msgcounter`, `seqcounter` are a positive override.
4. **high_entropy_analog** — `length >= 8` and `abs(scale) < 1.0` and the message is not multiplexed.
5. **other** — everything else.

Name matching is case-insensitive and is applied to the name with underscores removed, so `VCU_INV_RollingCounter` and `INV_Rolling_Counter` both match `rollingcounter`.

## Worst-N ranking

`N = 10`. The ranking itself is computed in plan 00-06 from measured bytes/frame, because it needs measurements this plan does not have. This plan exports `CATEGORIES` and the per-message classification that the ranking is reported alongside; it does not rank.
</interface_contract>
